# Lotus

Lotus is a macOS photo-culling app for reviewing a folder of photos quickly.

The app helps you:
- scan a local folder of images
- review photos in a keyboard-first workflow
- see a lightweight technical score with explainable reasons
- mark each photo as keep, reject, or undecided
- move rejected photos to Trash only after the review is complete and you confirm the action

## Day 1 Scope

Lotus is currently a local-only, macOS-only app focused on a simple review workflow for a few hundred photos.

It does not use cloud processing or backend services, and it does not delete files automatically during scanning or review.
